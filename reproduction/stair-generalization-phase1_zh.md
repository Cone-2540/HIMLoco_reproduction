# 楼梯泛化阶段 1：平地回放与指令覆盖

状态：代码和实验配置已准备，尚未启动本阶段 GPU 仿真或训练。上一轮冻结版本 `go2-stairs-overnight-20261011` 的完整验收仍为 **FAIL**；本阶段没有新权重或改进效果结论。原约七小时窗口为北京时间 2026-10-11 00:29:13–07:29:13，追加训练时长的问题仍等待回复，准备工作只进行了 CUDA 屏蔽的 CPU 检查。

上一轮楼梯权重的平地回归仅 3/6 指令通过，后退和负转弯几乎没有响应，正侧移 64/64 跌倒。楼梯训练只覆盖前向运动，可能参与了能力遗忘；这是待验证的假设。阶段 1 保持现有奖励与 HIM 结构，只比较回放地形和指令覆盖。

| 组别 | 地形 | 平地指令 |
| --- | --- | --- |
| A | 原楼梯课程 | 无平地回放 |
| B | 75% 原楼梯、25% 真正平面 | 原前向和航向指令 |
| C | 与 B 相同 | 10% 静止；前进、后退、左右侧移、正负纯转各 15% |

B/C 保留全部 48 种 hard 楼梯变体，新增 16 个连续平面列，共 64 列。4096 个环境中预期 1024 个平地、3072 个楼梯；启动后另保存实际环境和指令读回。A 使用 4096 个楼梯环境，所以 A 与 B 的楼梯采样量不同；不能声称三组楼梯训练步数相同。配对续训种子也不代表随机轨迹逐步相同。

平地不参与楼梯目标、楼梯走廊失败或难度升降。机器人可以跨相邻平面块运动；接近整个平地矩形外边界 1 米内时按 timeout 截断，避免进入楼梯或地形边框。边缘出生会缩短部分回合，独立记录平地 reset 和边界 timeout，不能把它们算作成功上下楼。C 的平地禁用父采样器的 heading/standing 覆盖，楼梯仍沿用原前向采样，并显式设置 `turn_fraction=0`。

三组都从 `artifacts/go2-stairs-control660/model_660.pt` 完整恢复 actor、critic、HIM、std 和两个 Adam 状态，校验起点 SHA256；不用 warm start，不重设探索标准差。actor 保持 45×6=270 维历史，critic 为 235 维，187 个地形高度仍只进入 critic。

[机器可读计划](stair-generalization-phase1-plan.json) 固定每个组别/续训种子的任务为 4096 环境、每更新 100 步、100 次保存更新，共 40,960,000 环境步。续训种子为 1001/1009/1013，九次正式任务合计 368,640,000 环境步，两学习率均为 1e-4。先用 C 做 128 环境、3 次更新的 GPU 预检；预检权重不参与组间选择。若追加窗口不足，未完成的组按不完整实验报告，不给单组额外预算再做公平性声明。

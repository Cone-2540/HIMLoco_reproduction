# Go2 HIM：下一独立阶段的控制实验计划

这是一份后续计划，本轮没有据此生成新权重，也没有启动训练或仿真。目标是同时恢复通用运动能力、提高长梯与首阶可靠性，再优化运动质量；不以单个成功录像或较低的惩罚代理值代替验收。新阶段须建独立 Git 分支、运行源快照和协议，保留本轮冻结结果及 FAIL 结论。

## 本轮依据与待检验解释

- **数据支持**：冻结楼梯权重的标称平地回归只有 3/6 指令通过；后退和负向转弯几乎不响应，正向侧移 64/64 首轮跌倒。见 [平地回归](stair-policy-frozen-flat-regression.md)。`isaaclab/run.py` 的本轮楼梯配置使用正向 `vx=0.25–0.65 m/s`、`vy∈[-0.03,0.03]`、固定 `heading=0`，所有环境采用 heading commands；缺少持续的后退、侧移和双向纯转弯训练覆盖。**待证假设**：这一分布收缩参与了能力遗忘；不能把它宣布为唯一原因，地形分布、优化过程、探索及奖励也可能参与。
- **数据支持**：标准楼梯外部航向反馈为 1152/1152 完成，零 yaw 指令为 1050/1152。长梯诊断的 123 个越界终点全部由 RR_foot 触发，root 仍在边界内；航向反馈没有横向位置项。见 [航向依赖](stair-frozen-heading-dependence.md)、[失败诊断](stair-frozen-failure-diagnosis.md)。**待证假设**：训练中缺少充分的侧向恢复与长时间累积误差暴露，可能导致这种偏移；尚未由配对训练消融证成。
- **数据支持**：低速 23/20 cm 下楼的 34 个跌倒中，33 个 root 终点位于首个踏面；另有小腿承载而对应足端无接触的停滞样本。高摩擦带边沿上楼也会停滞。见 [陡梯关联诊断](stair-stretch-association-review.md)。**待证假设**：首阶足端布置、碰阶与小腿支撑可能形成不良局部解；终点和稀疏轨迹不足以确定碰撞点或因果。
- **数据支持**：高／低摩擦表现差异明显，动力学扰动在 0.3 和 0.5 m/s 的三个构造种子均未通过完整矩阵，且常规几何也有失败。见 [最终验证](stair-frozen-final-validation.md)、[材料补充](stair-frozen-material-speed05.md)、[动力学补充](stair-frozen-dynamics-speed05.md)。单个低摩擦条件通过不代表材料范围鲁棒。

## 每组实验共同设置

1. 首组从归档 **control660** 起步，SHA256 为 `79fcc69b9447ecfb4df9fcfb41224cdab78632649f38fd9faf09c7b6adf69c61`。一组内所有实验臂复制同一完整 checkpoint，恢复 actor、critic、HIM、std、PPO Adam 与 HIM Adam 动量，不用 `warm_start reset` 混入优化器重置。后组从前组仅按开发验证集选择、重新冻结的共同起点开始，始终保留未改动对照。
2. 固定 **4096 环境 × 100 policy 步／更新 × 100 次已保存更新**，每臂 40,960,000 环境步；固定 PPO/HIM 学习率 `1e-4`，保持本轮 PPO 超参数、5 epochs、4 minibatches、20 ms policy／5 ms physics 及探索初值。每臂至少使用三个配对续训种子 **1001/1009/1013**，报告全部三份权重，不只发布最优一份。这是三个续训重复，不能称三个从零训练重复；GPU 也不保证逐位确定性。若预算不足以恢复能力，另立全臂同预算的 200-update 实验，不能单给某臂追加训练。
3. actor 保持 **45×6=270 本体历史**及原 HIM；critic 保持 **235 维**，187 个高度只供 critic。新增平地区域仍保留相同的 critic 高度采样语义，避免尺寸切换。地形、足端位置、表面法向和接触信息可用于训练奖励／诊断，**不加入 actor，不假定真机具备地形感知**。
4. 单 GPU 顺序运行，先以短启动测实际吞吐与显存，再估算整组时长；不为凑满显存盲目增大 batch。大改前后 commit，记录启动 commit、源码／配置／checkpoint hashes、完整优化器状态与实际保存更新数。保持已有容器、共享资源位置，显卡驱动和系统 GPU 配置不动。

## 为什么不先加大平滑／力／滑移惩罚

**已有证据**：同起点、同 40 次更新的 force660 在调参矩阵为 2302/2304，control660 为 2304/2304；force 的若干动作／jerk／接触均值改善，却有一个场景／种子退化到 30/32。见 [匹配力惩罚比较](stair-force-controlled-comparison.md)。最终长梯下楼的 slide680 脚滑代理下降，却在 0.3／0.5 m/s 分别仅 65/96、26/96，control 为 96/96、73/96。slide 比 control 多 20 次更新，且只有一个训练 seed，不能宣布滑移奖励单独造成了退化。

**待证机制**：更强的动作平滑可能抑制首阶快速调整；接触／力惩罚可能鼓励少动或过早撤去必要支撑；world-XY foot-link 速度惩罚可能把正常脚端运动与真实切向打滑混为一谈。提前失败还会缩短测量时长，让 jerk／接触均值看起来更低。这些机制需要配对、多种子实验与稠密接触观测，不能由现有均值直接证明。第 4 组首先改善接触语义，而非继续放大同一代理惩罚。

## 开发验证、独立保留集与共同 gate

训练和开发验证可以使用本轮已打开的全部几何，但不能继续称它们“新保留集”。下一阶段在首次训练前写入新的 JSON 协议和 hash，最终保留集不得参与课程、参数选取或 checkpoint 选择。例如从未用作本轮最终几何的 **15.3／18.7／21.5 cm 高、24／31／36 cm 深、9／14 级、1.2／2.2 cm 边沿及 1.0／1.35 m 宽**中预注册代表性组合，保留上下楼及平台过渡；它们须与开发集按几何组合分离。使用新 reset seeds **701/709/719**、新 construction seeds **131/137/139**，保存每环境完整初态位置、四元数、速度、关节和实际物理参数，不能只保存 root XYZ 或总体分布。材料与动力学分别测试，再增加联合压力组。

固定更新点只按开发集共同指标选择；最终一次性冻结全部候选／种子／源码／门槛后打开保留集。失败即归档，不再据其结果续训或重选模型。至少三训练 seed 均报告每个 case×reset×construction 的结果与不确定性，不能把三次初态测试当作三次训练复现。

- **完成与安全**：沿用每 case／seed≥95% 完成、fall／stall／足端 escape 各≤5%、history-base 接触为零，每 case／seed 至少 32 env；四脚到目标平台，首轮失败不能被 reset 成功覆盖。继续记录 root 与四足边界，尤其 RR_foot；另列完全零失败率。
- **跟踪与全向平地**：楼梯同时报告 XY/yaw tracking、航向与横向误差；默认 heading 与零 yaw 指令分开验收。平地至少 64 env×20 s×三个新初态 seed，包含本轮六指令以及负向侧移和混合移动／转弯；保留原 `XY MAE<0.2 m/s、yaw MAE<0.3 rad/s、survival≥95%` 门槛，每条指令都过。楼梯改善不能抵消平地回退。
- **足端、接触与运动**：保存 20 ms 动作／root 运动和四足轨迹，接触采集覆盖完整四个 5 ms 子步，区分足端支撑、小腿支撑、当前／历史及冲量／持续时间，报告局部表面切向速度；保留原 foot-link proxy 以便对照。原 roll RMS 0.15 rad、峰值 0.35 rad、长停顿 1 s、脚滑 proxy 0.15 的参考及完整连续视频要求继续单列。pitch 相对坡度解释。只在两臂均完整、成功的同几何／速度／初态配对轨迹比较 action 二阶差分、jerk 与接触；失败轨迹也完整保留，不能通过剔除失败获得更低均值。
- **共同通过**：只有完成、跟踪、全向平地及运动质量同时满足预注册要求才晋升。接触持续承载和动作／jerk 的额外绝对上限须在开发集设定并冻结后验收，不从最终结果倒推阈值；完整实时连续播放审查包括上下楼、入口／出口、长梯、高摩擦边沿和代表失败。统计完成门槛通过不自动等于“丝滑”。

最终交付仍应明确是 Go2 的 Isaac Lab 迁移实验，不能称原 Isaac Gym 软件栈完全复现；仿真改进也不构成 Go2 EDU 真机部署许可或效果保证。实机阶段另行标定执行器、延迟和摩擦并设计渐进测试。
